swiftdrop/

SwiftDrop

Role-based delivery management web app in Flutter and Firebase — dispatchers assign orders, drivers work through optimized stops, and every screen updates in real time via Firestore streams. Status changes run inside Firestore transactions that re-validate the current state before committing, preventing two drivers from claiming the same order, and driver routes are computed with nearest-neighbour construction plus 2-opt improvement over haversine distance.
